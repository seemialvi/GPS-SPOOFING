Keep the render rate equal to the transmit rate (-s is passed to both). Signed 8-bit I/Q uses 5.2 MB/s at 2.6 MS/s, so 750 s is about 3.9 GB. The file plays once so GPS time always moves forward during acquisition. Digital dBFS is sample amplitude; receiver acquisition requires independent serial evidence.
